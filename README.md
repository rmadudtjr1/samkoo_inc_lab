# 삼구 Gemini Enterprise 실습 교재

삼구 보안·IT팀과 DX팀을 위한 Gemini Enterprise 3시간 실습 교재입니다 (2026-10-29).

- `index.html` 한 파일로 된 웹 교재입니다. 브라우저로 열거나 GitHub Pages로 게시해 사용합니다.
- 구성: 시간표, Ch.0 왜 Gemini Enterprise인가(Workspace의 Gemini와 비교), Ch.1 어시스턴트·Deep Research, Ch.2 프로젝트·Notebook, Ch.3 스킬, Ch.4 대화형 에이전트, Ch.5 시연(워크플로·Antigravity), 경진, 실습 자료실
- 실습 자료는 모두 교육용 가상 자료이며 실제 회사 규정·직원과 관계없습니다.

## GitHub Pages로 게시하기
Settings > Pages > Source: `Deploy from a branch`, Branch: `main` / `(root)` 저장 후 몇 분 뒤 게시 주소가 표시됩니다.
